# 是什么
当唱歌唱到副歌, 或者音调比较高的段落时, 出现了音色挤卡, 颈部很累, 不能咬字, 无法继续唱, 就是挤扯

## 原因

发声时你的其他协同肌群代偿发力
比如胸锁乳突肌(侧头, 歪头, 伸头, 点头)
吞咽肌肉群

吞咽肌肉群最好不要参与发声
借力的行为会强化你的协同肌群，而不是主动肌。过度代偿会导致
1. 高音喉位太高
2. 脖子僵硬，很累
3. 感觉无法唱出高音
4. 舌头后缩紧绷，疲惫
# 建议
1. 吞咽肌肉群不要发力
2. 演唱的过程中，不转头，不伸头，不侧头，不用力的唤起，不要过分的绷紧胸锁乳突肌
3. 舌骨下肌群，可以绷紧
4. 表情肌不要太夸张
# 吞咽肌肉群不发力
### 方法一：伸出舌头

最大程度的伸出舌头，
用力伸出，然后感受吞咽肌肉群，
应该会有一点硬，
这个硬度不算在过分绷紧当中

### 方法三：起音前用气泡音带出
