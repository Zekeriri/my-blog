# 是什么
环倾就是当代的一种大声的演唱方式, 在高音中就是有力量的, 激动人心的
环状软骨倾斜是一种比较有效率的, 能把声带缩短, 变厚的动作
# 环倾动作
提示词:
呐喊"yeah!!" (超级开心)
体感: 
环状软骨凹进去了
# 注意
不要推气(主动和被动都会导致假声带内缩)


平时可以利用琐碎的时间
练习环倾的无声动作
脑海里面想一个音高
然后假装自己在呐喊
对以后的发声有积极影响

# 训练
## 1. 短音下滑
C4-C5, 保持真声维持1s或更少
## 2. 短音重复
最少三次环倾

# 3. 长音
三秒以上

# 注意
注意练习时长
可以加入一点甲倾(侧收, 有感情)
