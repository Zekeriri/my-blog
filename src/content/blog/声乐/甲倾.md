# 混声原理
EVT把声带的发声形态分为4种, 厚, 薄, 僵硬, 松弛
对于SLS, 现代声乐教学中的胸声(真声), 头声(假声), 假声, 气泡音
混声就是藏在真声中间,不厚不薄,适中的声带模式

# 甲倾

甲倾是一种比较效率的,拉长声带的作用
提示词是
发出伤心小猫咪的声音
伤心,抱怨,失望,同情,温暖的语气
喉位高不用在意,如果能做到中喉位最好
不要过分的悲伤(会导致喉位下降, 舌头后缩),接近快哭了就可以了

# 运用
无声啜泣, 保持呼吸(就是用鼻子吸)
可怜楚楚又温暖的音色
要独立出来,无声,不要收腹

# 作用
甲倾有侧收假声带的效果-解决挤扯
甲倾拉长声带有让高音更高的效果-解决不够高
甲倾听起来是温柔的音色-解决太用力喊的音色

# 注意事项
如果挤扯
1. 加大甲倾力度
2. 保持或者减少咽音力度
3. 锚固头颈身躯（减少气息使用）
破音, 虚弱, 撕裂
4. 保持一定甲倾力度（不可以没有）
5. 增加咽音力度（不破之后可以减少）
6. 锚固头颈身躯（减少气息使用）
