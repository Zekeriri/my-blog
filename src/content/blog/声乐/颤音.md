# 是什么
抖动的声音
在半音内或大于半音都有, 没有绝对的幅度
有合适的频率

颤音与喉内的抖动有关
并不是高低喉位的移动
抖动动作不受喉位高低影响

颤音是通过甲倾抖动制造的颤音

# 产生方法
步骤一：启动甲倾
舒适力度甲倾，幅度小，不要推气辅助
核心腹肌绷紧允许，但不要突然收腹即可
步骤二：重复甲倾
速度可以从慢开始加快，不需太快
感受甲倾发力点(下颌处，喉结处)
如舌头后缩紧张可以咬住舌头练习
步骤三：连接甲倾
连接并保持甲倾抖动，不爆发推气(自行锚固)
不刻意唱半音阶，回到原来的音高

# 练习1-元音
目的: 稳定熟练颤音
步骤一: 元音练习
aiueo, 头声-假声, 真声-胸声
选择舒适音调即可

步骤二: 默数频率
可以搭配手势辅助
一次练习至少7-9次颤音, 开始用中等, 慢速进行
# 练习2-稳定提速
目的: 加快颤音频率
从慢速开始，以稳定为基础，慢慢加快，
不着急，提速不推气，窍门心得：哭快一点
